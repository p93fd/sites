# Сайт-фильм (kino-kit)

Набор лежит в репозитории p93fd/sites, папка `tools/kino-kit/` (README — порядок и нормы). Пример — `steklo-swipe/`.

## Что делает сайт дорогим (проверено на победителях Awwwards и у Apple)

1. **Кадр идёт за рукой, а не включается кнопкой.** Свайп и колесо двигают камеру в обе стороны, отпустил — она мягко доезжает до сцены. Ролик по свайпу — дешевле.
2. **Ничего не замирает.** В покое: петля камеры, свет дышит, частицы. Ни одной статичной картинки.
3. **Пружина без перелёта** вместо резких остановок: мягкий разгон, мягкая остановка, скорость ограничена.
4. **Одна гамма, один мир.** Каждая сцена вырастает из предыдущей: пролёт сквозь объект, а не смена картинок.
5. **Текст в покое чёткий.** Без размытия и движения, проявляется на подлёте, уходит при первом движении.
6. **Сдержанность.** Движение — чтобы вести взгляд, не для шума. Плёнка: зерно 2–5%, пыль, виньетка.
7. **Скорость.** Плёнка целиком в памяти до открытия, каждый кадр ключевой. Анимируются только transform, opacity и filter.

## Порядок работы

1. Собрать вводные: смысл каждой сцены, цвета, 8–10 сцен. Сцена N+1 должна быть продолжением сцены N.
2. Ключевые кадры — бесплатно (Gemini / Nano Banana, FLUX на Hugging Face, свой рендер Three.js). Общий стилевой префикс на каждый кадр.
3. Пролёты: Wan 2.2 «первый + последний кадр» (Hugging Face, бесплатный токен), промпт описывает только движение камеры.
4. `build_seg.py` → `build_scrub.py` → `idle_loops.py` (наборы d и m) → `idle_webm.sh`.
5. Скопировать `engine/` в папку сайта, настроить пути (`data-assets`, `data-film`), силу жизни сцен (`P` в live.js) и частицы (`SC` в particles.js).
6. Проверить в браузере до выдачи (ниже). Запушить на GitHub Pages.

## Проверка до выдачи (обязательно)

- Скриншот каждой сцены в покое дважды с разницей 1,5 с: разница больше 1.5 — значит, живое.
- Скриншоты на ходу: текст скрыт, кадр плёнки верный.
- Свайп туда и обратно, бросок, прыжок через точки навигации.
- Ошибок в консоли 0. Вес: компьютер не больше 40 МБ, телефон не больше 20 МБ.
- Посмотреть глазами общий лист всех сцен, только потом отдавать.

## Нельзя

- Платные сервисы и подписки. Если бесплатный лимит кончился — следующий бесплатный путь, а не оплата.
- Резкие остановки, «ролик проиграл — стоп-кадр», текст поверх движущегося кадра.
- Мелкий шрифт с важным смыслом.
