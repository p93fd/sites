## 1. Минимальные размеры шрифта
- Основной текст десктоп 15-19px, мобайл 15-17px; html font-size у Locomotive 15/17/19/21px по брейкпоинтам [locomotive]
- Основной текст 16px (1rem), подписи/caption 13px (.8125rem) на десктопе и мобайле [pentagram]
- Body-1 13-15px, body-2 16-21px (масштаб по vw от макета 1440), абзац проекта 18-21px [instrument]
- Body у Work & Co 16px (1.6rem при html 10px), вторичный 14px, самый мелкий 12px [work.co]
- Самый мелкий осмысленный текст: 12px, 600 вес, line-height 16px; на десктопе 13px [basement]
- Декоративные микро-метки (UPPERCASE, трекинг .05-.11em): 9-11px, только оверлайны и номера [instrument: caption-1 9-10px, caption-2 10-11px]
- Метка имеет смысл только если ей не нужно ничего читать: всё, что человек должен прочитать, не меньше 12px и то с весом 600 [basement]
- Подписи к чипам/тегам кейса 12px (.75rem) [basement]

## 2. Кейсы, проекты, отзывы
- Фото кейса 16:9 на всю ширину колонки (aspect-video, w-full), в сетке 2 колонки иногда span 2 [basement]
- Варианты пропорций у Locomotive: 16:9, 5:7 (портрет), 6:10, квадрат 100%, 133% [locomotive]
- Рамка на фото: 1px border rgba(230,230,230,.2) поверх картинки (псевдоэлемент ::after inset:0), радиус 0 [basement]
- Название проекта крупно (h1 "huge" ~7.6vw / 40px на мобайле), под ним одна строка-описание ("Off-road heritage") [locomotive]
- Теги услуг (Branding / Digital / E-commerce) списком li под заголовком, мелко [locomotive]
- Блоки страницы кейса: About, Awards (N), Credits, Next Project, у каждого оверлайн-заголовок [locomotive]
- Аватар клиента: круг 14-18px (size-3.5/4.5), 1px border w1/20, фон #2e2e2e [basement]
- Имя клиента и мета-строка 12px/16px, вес 600, рядом с кружком, gap 4-8px [basement]
- Цвет не гасят до ч/б: фото в полном цвете, hover меняет цвет текста/метки на акцент, не картинку [basement]
- Градиент-оверлей под подпись поверх фото: (по памяти) от rgba(0,0,0,.6) к 0, высота 40% кадра
- Подпись к фото в 12-13px под фото, не поверх (по памяти)

## 3. Цифры и показатели
- Сетка stats: каждая ячейка с border-top 1px и padding-top ~8-20px, цифра под линией [locomotive: c-stats_item]
- Число в 3-4 раза крупнее подписи: h1-класс 33-47px против подписи 15-18px [locomotive, шкала h1/medium]
- Display-цифра 58-131px (3.6-8.2rem) против 13-16px подписи, соотношение 6-8x [pentagram display-1]
- Выравнивание по левому краю колонки, подпись одной строкой под числом [locomotive]
- Разделитель: только верхняя линия 1px currentColor, без вертикальных линий [locomotive]
- Число 400-600 веса, трекинг -.02..-.04em [instrument display -.01..-.03em; basement h0 -.04em]
- Контейнер ячейки container-type:inline-size, число масштабируется от ширины ячейки [locomotive]

## 4. Списки из 4-6 пунктов
- Строка: линия сверху 1px, padding 16-24px по вертикали, номер слева отдельной колонкой (по памяти: 40-80px)
- Заголовок пункта 18-24px (h3 1.5rem/1.25rem на мобайле, line-height = размеру), описание 13-16px [basement h3 / p]
- Описание цвета secondary (#c4c4c4), заголовок primary (#e6e6e6) [basement]
- Межстрочный: заголовки 1.0-1.05, текст 1.25-1.3 [pentagram 1.05/1.25; locomotive 1.3]
- Разделители: border-bottom 1px, у светлых #e3e4e5 [pentagram]; на тёмном rgba(230,230,230,.1-.2) [basement]

## 5. Рамки и скругления
- Рамка на тёмном: rgba(230,230,230,.1) тонкая, .2 стандарт, .3 hover/активная [basement border-brand-w1/10,/20,/30]
- Плотная линия карточки: #2e2e2e (сплошной) [basement brand-g2]
- Hairline = 1px везде, акцентная линия 2px [locomotive --border-size 1px/2px]
- Радиус: 0 у фото и карточек, 9999px у кнопок/чипов/аватаров, 8px у мелких блоков, 24px у крупной карточки [basement, pentagram, instrument]
- Паддинг карточки: (по памяти) 20-32px; у Basement отступы ячеек 1-2rem (gap-1 / gap-2)
- Рамка вокруг фото делается псевдоэлементом поверх, чтобы не сдвигать размер [basement]

## 6. Контраст текста на тёмном
- Фон: #000000 [locomotive, basement]; #070708 [instrument]
- Primary текст: #e6e6e6 (не чистый #fff), #f1f1f1 [basement, instrument]; чистый #fff только у Locomotive
- Secondary: #c4c4c4 (~12:1 на чёрном) [basement brand-w2]
- Tertiary: #757575 (~4.6:1 на чёрном, это нижняя граница для читаемого текста) [basement brand-g1]
- Приглушение через opacity: .5 у вторичных подписей [locomotive: opacity:.5 в 13 местах]
- Overlay/затемнение: rgba(7,7,8,.12/.5/.75) [instrument]; rgba(0,0,0,.65) [locomotive]
- Акцент один: #ff4d00 (оранж) у Basement, #312DFB (синий) и #DA382E у Locomotive [basement, locomotive]

## 7. Отступы и ритм
- Шкала секций: 40 / 80 / 150 / 200 / 250px десктоп; мобайл 40 / 52 / 80 / 100 / 140px [locomotive --spacing-*]
- Мелкие шаги: микро 8px мобайл [locomotive]; сетка 8px (baseline 8) [instrument --baseline]
- Внешний gutter 32px, внутренний 12-16px [pentagram --outer-gutter/--inner-gutter]
- Заголовок -> текст: 16-24px; между блоками в сетке gap 12px по вертикали, 4-8px у мелких групп [basement gap-y-12 = 3rem между рядами]
- Масштаб по vw: размер = значение/1440*100vw на десктопе, фикс px на мобайле [instrument, locomotive]
- Максимальная ширина читаемого абзаца ~420px (26.25rem) [basement max-w]

## 8. Кнопки и ссылки
- Кнопка-таблетка: padding 6px 12px (py-1.5 px-3), UPPERCASE, 12px, radius 9999px [basement]
- Заливка не ставят: текст w1, hover меняет цвет на акцент #ff4d00, transition-colors [basement]
- Focus: ring 1px акцент [basement]
- CTA как ссылка: подчёркивание толщиной = --border-size (1px), стрелка 75% размера текста через 0.5em [locomotive c-button_label]
- Радиус 50px и круги 50% у pill/иконок; 0 у прямоугольных [work.co, locomotive]
- Размер текста кнопки не меньше основного (15-16px) на мобайле (по памяти)
- Контурная кнопка: 1px solid rgba(230,230,230,.3), hover заливка rgba(255,255,255,.05) [basement tweet-bg-hover #ffffff0d]

## Правила для сайта эксперта на тёмном фоне
1. Жёсткий пол: любой текст со смыслом не меньше 14px на телефоне и 16px на десктопе; абсолютный минимум 12px только для подписи к фото и тега, вес 500+.
2. Основной абзац 17-19px десктоп, 16px мобайл, line-height 1.3-1.4, ширина строки 420-560px.
3. Микро-метки (номера, оверлайны) 11px и выше, uppercase, letter-spacing .06em, только как украшение, смысла не несут.
4. Фон #000 или #070708; primary #e6e6e6; secondary #c4c4c4; tertiary #757575 и не темнее.
5. Чистый #fff только для заголовка и числа, остальное #e6e6e6.
6. Фото кейса 16:9 на всю колонку, полный цвет, без ч/б, радиус 0, рамка 1px rgba(230,230,230,.2) поверх.
7. Имя клиента, роль и результат стоят под фото одной группой: имя 16px/600, роль 14px secondary, результат отдельной строкой ниже; поверх фото ничего.
8. Портрет клиента: круг 40-48px, border 1px rgba(230,230,230,.2), рядом с именем, не вместо фото кейса.
9. Число результата: clamp(48px, 6vw, 96px), вес 500, трекинг -.03em; подпись под ним 15-16px secondary; соотношение не меньше 4:1.
10. Ячейки с числами: border-top 1px rgba(230,230,230,.2), padding-top 16px, выравнивание по левому краю, колонок 2-4, вертикальных линий нет.
11. Список из 4-6 пунктов: строка с border-top 1px, padding 20px 0, номер 14px в колонке 48px, заголовок 22-24px/1.1, описание 15-16px secondary.
12. Рамки: 1px rgba(230,230,230,.1) для разделителей, .2 для карточек, .3 для hover; радиус 0 у фото и карточек, 999px у кнопок и чипов.
13. Отступы секций: clamp(80px, 11vw, 160px) по вертикали, мобайл 72-80px; заголовок -> текст 20px; gap сетки 12-16px, внешний gutter 32px десктоп / 16px мобайл.
14. Кнопка: padding 14px 28px, 16px/500, radius 999px; основная залита акцентом, вторая контур 1px rgba(230,230,230,.3); hover плавно за 200ms меняет цвет, высота не меньше 48px.
15. Один акцентный цвет на весь сайт, использовать для hover, фокуса и одной главной кнопки; подчёркнутая ссылка 1px, не менее 15px.
