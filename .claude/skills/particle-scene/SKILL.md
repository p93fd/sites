# Сцена из частиц

Рабочий образец: `sistema/app.js` в `p93fd/sites`. Источники и формулы: `research/wave1-eu-creative-dev.md`, `research/wave2-deep.md`.

## Каркас

- Чистый three из своих файлов (`lib/three.module.min.js` и `lib/jsm/`), карта импортов. Без сборки не подключать `@react-three/fiber` с открытых CDN: приходят две копии React и three, страница падает.
- Одна геометрия `Points` на сетке u×v: 236×124 на компьютере, 150×92 на телефоне. Каждая форма — свой атрибут `vec3` (до шести форм на одну геометрию).
- Линии — `LineSegments` с теми же атрибутами и тем же шейдером формы: строки сетки и столбцы отдельно, чтобы гасить их по формам.

## Перетекание

```glsl
float i=floor(uP), f=uP-i;
float n=snoise(vec3(aUV.x*3.2,aUV.y*2.4,i*7.31))*.5+.5;   // плавный шум по сетке
float delay=.55*(n*.62+aUV.y*.38);                          // соседи уходят вместе, волна идёт по сетке
float ff=clamp((f-delay)/.45,0.,1.); ff=ff*ff*ff*(ff*(ff*6.-15.)+10.);
float pe=i+ff;  wK=max(0.,1.-abs(pe-K));                     // веса форм
```

- Турбулентность только в середине: `k = sin(π·ff)²`, смещение тремя вызовами шума по сетке. В покое форма чёткая.
- Прокрутка → состояние: `target = k + smoothstep(0.34, 1, f)` — первая треть шага форма стоит. Сглаживание `1 - exp(-5.2·dt)`.
- Линии гасить на переходе: `(1 - sin(π·ff)·0.85)`.

## Глубина и материал

```glsl
float base=size*uScale/z;                                     // uScale = высота·dpr / (2·tan(fov/2))
float coc=abs(z-uFocus)*uAp*uScale*.0042;                     // круг нерезкости
float sizePx=max(1.4,base+coc);
float energy=clamp(base*base/(sizePx*sizePx),0.,1.);          // чем больше диск, тем он тише
```

- Фокус ведётся за целью камеры; на переходе апертура растёт.
- «Бусина»: в фрагменте нормаль из `gl_PointCoord`, диффуз и блик; смешивать с мягким диском только у точек в фокусе и крупнее 4–7 px. У форм разный материал: спираль — бусины, галактика — точки света.
- Разнообразие: размер и яркость на точку, 6 % горячих, мерцание `sin(t·f + seed)`.
- Воздух: дальняя пыль и 3–6 ближних дисков боке. Больше — выглядит дёшево.

## Свет

- `EffectComposer` (буфер половинной точности) → `RenderPass` → `UnrealBloomPass(сила 0.36, радиус 0.5, порог 0.5)` → линза → `OutputPass`.
- Тональная кривая на рендерере: `ACESFilmicToneMapping`, экспозиция 1. AgX мягче и серее, пробовать параметром.
- Фон задавать `scene.background`. `renderer.setClearColor` при постобработке в three r160 пишет цвет без перевода в линейное пространство: чёрный выходит серо-синим.
- Хроматическая аберрация едва заметная: `0.008 + 0.012·переход + 0.012·скорость`. Сильнее — выглядит сбоем.

## Сцена и текст

- Текст в HTML. Прямоугольник активного блока передаётся в шейдер (`uRect`), внутри точки тише (×0,16) и мельче (×0,7), кромка мягкая 0,11.
- Камера на главу своя: цель смещена так, чтобы масса объекта ушла на половину экрана, свободную от текста. Для узкого экрана отдельный набор.
- Число из частиц: растр настоящего шрифта на canvas (`ctx.font`, затем `ctx.fontStretch`), точки с шагом 3 px, сортировка по x. В шейдере число ставится по прямоугольнику пустого блока в вёрстке: `ширина_px × мир_на_пиксель`.

## Устройства

- Плотность пикселей: телефон до 1,5, компьютер до 1,75. Каждые 50 кадров мерить среднее: больше 24 мс — шаг вниз на 0,25; меньше 12,5 мс — шаг вверх.
- Высота канваса `100lvh`; изменение высоты меньше 160 px на сенсорном экране не пересчитывать.
- `visibilitychange` — остановить цикл. `webglcontextlost` — показать страницу без сцены, после возврата перезагрузить.
- Сниженное движение: вход без разлёта, турбулентность 0,2, аберрация 0, время идёт втрое медленнее.
- Нет WebGL: класс `nogl`, фон градиентом, число показывается шрифтом.

## Проверка

- `node tools/shots.mjs <папка> --qs "?hq&fix"`: `hq` включает полную версию в безголовом браузере, `fix` выключает подстройку плотности.
- Пиксели канваса не читать через `drawImage` — будет чёрное. Смотреть снимок страницы.
- Цвет фона мерить пипеткой по снимку: должен совпасть с `--bg`.
- На каждом экране ответить, где здесь глубина и что форма говорит о заголовке.

## Образец пользователя (видео TEXTURA, 06.10.2026) — что в нём главное

- Это частицы, но плотные и мелкие: 200 тысяч точек на компьютере (сетка 560×360), 60 тысяч на телефоне, размер около 1–2 px. Крупные редкие точки он называет «пикселями» и отвергает.
- Сильное мягкое сияние: свечение 0,7, радиус 0,72, порог 0,32; непрозрачность точки 0,55.
- Два тона: холодное тело (синий → голубой) и горячая кромка (красно-малиновый) пятнами по шуму.
- Формы по порядку: сфера с яркой кромкой, воронка-вуаль, двойная спираль, волна, финал — яркое ядро с диском и тремя орбитами. Кольцо, спиральную галактику и гладкий «литой» объект он отверг.
- Линии сетки почти не видны (0,12 и 0,07): структуру держит плотность точек.
- Перед любой правкой графики резать образец на кадры (`ffmpeg … tile=9x2`) и сверять с листом снимков.
