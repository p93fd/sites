## Грабли, найденные на этом сайте

1. three r160: `renderer.setClearColor` при постобработке пишет цвет в линейный буфер без перевода — фон выходит серо-синим. Фон задавать через `scene.background`.
2. `@react-three/fiber` с открытых CDN без сборщика тянет вторую копию React и three и падает. Без сборки — чистый three из своих файлов.
3. `ctx.fontStretch` на canvas ставить после `ctx.font`, иначе ширина сбрасывается.
4. Чтение пикселей WebGL-канваса через `drawImage` даёт чёрное: проверять снимком страницы.
5. В безголовом браузере мало ядер — включается облегчённый режим. Для снимков полной версии нужен параметр `?hq`.
