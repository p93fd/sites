# Решения (новое сверху)

## 2026-10-19 steklo v11: лёгкий, без тормозов на iPhone
Решение: фильм — кадры-картинки на холсте (f/d 1280×720 и f/p 540×1080 для телефона, 20 к/с, наплыв соседних кадров), грузятся от текущей сцены; открытие за 2 с и 0,3–0,5 МБ; петли покоя для телефона вертикальные (pi*.mp4); карточки без размытия; версии скриптов ?v=.
Почему: «тормозит всё, грузится долго, ничего не обновляется» на iPhone 17 Pro Max.

## 2026-10-19 steklo v10: плавно, бесшовно, золото
Решение: кадр едет за пальцем (плёнка, пружина), петли покоя играет браузер без шейдера, лотос рассыпается 3D-частицами из кадра (lotus.js, видеокарта), текст в карточках с золотой окантовкой и золотыми заголовками, мимо главного объекта сцены. v9 — в steklo-v9.
Почему: «тормозит, резкий, половина анимаций не работает», «лотос — отвратительная анимация», «текст с карточками, с золотой окантовкой и золотым цветом».

## 2026-10-19 Свайп туда-сюда без подписок
Решение: движок steklo-swipe + tools/kino-kit + скилл kino-sayt. Рабочий steklo не тронут до его выбора.
Почему: «хочется свайпать туда-сюда», «без единой подписки».

## 2026-10-19 Все слайды живые без остановок
Решение: петли покоя из своих роликов (neuro/idle_loops.py), шейдер live.js берёт картинку с петли, MP4 + WebM.
Почему: Apify без кредитов, внешние сервисы не нужны.

## 2026-10-18 steklo v5–v8
Решение: 9 сцен, 8 свайпов; переходы — готовые ролики 60 fps; плавная остановка; контраст +14%; живые частицы и свет на всех сценах.
Почему: «до конца максимум 8–10 свайпов», «плавнее, как у других», «всё живое».
Отклонено: кольцо кейсов (кейсы вылетают по одному из глубины), иконки слайда 2 прежние («отвратительные»).

## 2026-10-18 steklo по видео-образцу студии
Решение: фотореал на нейросетях (Nano Banana + Wan 2.2), цвета #4155e8 / #76b7ff, начало — небо, тоннель из световых плиток, вниз под воду, лучи и пыль.
Отклонено: кольцо в начале, кристаллы, чёрная точка в конце тоннеля.

## 2026-10-15 dengi
Решение: учёт денег по фото, распознавание в телефоне, без серверов (CSP connect-src 'self'), шифрование AES-GCM кодом 4–6 цифр; изумруд с золотом, цифры Cormorant.

## Постоянно принято
- Все экраны как одна форма, каждая картинка продолжает смысл предыдущей.
- Объём, мягкие переходы, плавная прокрутка.
- Сайт лёгкий, DPR не выше 2.
- Цену на сайте не показывать.
